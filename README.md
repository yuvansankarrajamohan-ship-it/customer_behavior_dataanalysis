# 🛒 Customer Shopping Behavior Analysis

## 📌 Overview

Customer Shopping Behavior Analysis is an end-to-end Data Analytics project designed to understand customer purchasing patterns, preferences, and spending trends.

The project analyzes 3,900 customer transactions to identify purchasing behavior, popular product categories, customer segments, discount usage, and subscription patterns.

The analysis uses Python for data cleaning and Exploratory Data Analysis (EDA), PostgreSQL for SQL-based business analysis, and Power BI for interactive dashboard development.

The main objective is to transform raw shopping data into meaningful business insights that help organizations make data-driven decisions.

## 📊 Dataset

- **Dataset Name:** Customer Shopping Behavior
- **Total Records:** 3,900
- **Total Columns:** 18
- **Data Format:** CSV

### Key Features

- Customer Demographics – Age, Gender, Location
- Purchase Details – Item Purchased, Category, Purchase Amount
- Shopping Behavior – Discount Applied, Previous Purchases
- Customer Information – Subscription Status, Review Rating
- Order Details – Season, Shipping Type, Payment Method

**Data Quality:** Identified 37 missing values in the Review Rating column and handled them during data cleaning.

## 🔄 Project Steps

### 1. Data Loading
- Imported the CSV dataset using Pandas.
- Loaded the dataset into Jupyter Notebook.
- Examined the dataset structure and data types.

### 2. Exploratory Data Analysis (EDA)
- Used `df.info()` to understand the dataset.
- Used `df.describe()` for statistical summaries.
- Identified missing values and duplicate records.
- Explored customer purchasing patterns.

### 3. Data Cleaning & Transformation
- Handled missing values in the Review Rating column using category-wise median values.
- Standardized column names using snake_case.
- Created an `age_group` column.
- Created a `purchase_frequency_days` column.
- Removed the redundant `promo_code_used` column.

### 4. SQL Analysis – PostgreSQL

Connected Python with PostgreSQL and imported the cleaned dataset into the database.

Performed SQL queries to answer 10 important business questions:

1. Revenue generated by male and female customers.
2. Customers who used discounts but spent above the average purchase amount.
3. Top 5 products based on average review ratings.
4. Average purchase amount comparison between Standard and Express shipping.
5. Spending comparison between subscribers and non-subscribers.
6. Top 5 products with the highest discount usage.
7. Customer segmentation into New, Returning, and Loyal customers.
8. Top 3 most purchased products in each category.
9. Relationship between repeat purchases and subscription status.
10. Revenue contribution by age group.

### 5. Power BI Dashboard

Developed an interactive Customer Behavior Dashboard using Power BI.

The dashboard includes:
- Total Number of Customers
- Average Purchase Amount
- Average Review Rating
- Subscription Status Analysis
- Revenue by Product Category
- Sales by Category
- Revenue by Age Group
- Sales by Age Group

Added interactive filters for:
- Subscription Status

### 6. Project Documentation & Presentation

- Created a detailed project report using Microsoft Word.

## 🎯 Results & Business Insights

The analysis generated the following insights:

- Male customers generated higher total revenue than female customers.
- Non-subscribers contributed higher overall revenue than subscribers.
- Express shipping customers had a higher average purchase amount than Standard shipping customers.
- Loyal customers represented the largest customer segment.
- Gloves received the highest average product rating among the top five products.
- Hats had the highest percentage of purchases with discounts applied.
- Young Adults contributed the highest revenue among the age groups.

### Business Recommendations

1. **Boost Subscriptions:** Introduce exclusive benefits to encourage more customers to subscribe.
2. **Customer Loyalty Programs:** Reward repeat customers to improve retention.
3. **Discount Optimization:** Review discount strategies to balance sales and profit margins.
4. **Product Promotion:** Highlight highly rated and popular products.
5. **Targeted Marketing:** Focus marketing campaigns on high-revenue customer segments.
